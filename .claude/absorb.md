## 화면 — 5번에서 옮겨 볼 화면들

**화면이 둘이다 — 폰과 벽.** 폰에서 좋았던 것이 벽에서도 성립하는지 본다.
벽은 손이 닿지 않고 멀리서 본다 — 자리와 손에 관한 원리는 대개 폰에만 해당한다.
`/admin`은 따로 볼 일이 없으면 뺀다.

카드의 **PC에서 / 폰에서** 두 줄 대신 **폰에서 / 벽에서**를 쓴다. 출처가 PC
사이트면 "출처" 줄에 PC에서 본 것이라고 적는다.

## 값 — 값 파일, 고르는 도구, 확인 도구

- **수치는 `src/styles/tokens.css`의 사다리 안에서 고른다.** 사다리에 없는 값이
  필요하면 **묻는다.** 메시지의 색은 예외 — `src/lib/palettes-v2.ts`(참여자가 고르는 내용)
- **값을 고를 땐 나란히 놓는다** — `tuning-grid` 스킬
- **넣은 뒤엔 열어서 본다** — `peek` 스킬(`scripts/lib/drive.mjs`). 폰 크기와 벽 크기 둘 다
- **폰 폭으로 남의 사이트를 열 때도** `drive.mjs`의 phone(390×844)을 쓴다 —
  Chrome 창 줄이기보다 믿을 만하다
- **폰 캡처 재기:** 아이폰 캡처 390×844는 `drive.mjs`의 phone 기본과 정확히 같다.
  우리 화면과 나란히 놓고 같은 자로 잴 수 있다.

```bash
python scripts/measure-reference.py "<캡처 폴더>"   # 여백·버튼·간격 양자화
```

- **폰에서 잰 간격을 벽에 그대로 쓰면 안 된다.** 보는 거리가 다르다.
- **`measure-reference.py`는 상태바와 홈 인디케이터를 이미 잘라내고 잰다.**

  작품이라 300ms 상한이 안 걸린다(`CLAUDE.md` 스타일 절).
