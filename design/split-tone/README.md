# 말투 선택 / 다듬기 분리

흐름: 말투(1/4) → 다듬기(2/4) → 한 줄(3/4) → 벽에서 보기(4/4).

첫 화면은 말투 네 가지에 집중한다. 다음 화면에서 발화 견본과 굵기·너비·기울기를 조절하며, 기본값 그대로 진행할 수 있다. 뒤로 이동하거나 말투를 바꿔도 조절값, 입력한 문장, 선택한 메시지 색을 유지한다.

사용자가 지정한 기기 색:
- #CF5B4C: 주요 버튼, 말투 선택 테두리·체크, 진행 표시.
- #3CCED0: 굵기·너비·기울기의 선택된 값.
- 검정: 제목과 컬러 버튼의 글자.
- TDS grey700 #4E5968: 본문.
- TDS grey600 #6B7684: 보조 정보.
- TDS grey200 #E5E8EB: 구분선, grey100 #F2F4F6: 보조 표면.

회색 출처: https://tossmini-docs.toss.im/tds-react-native/foundation/colors/
역할 배치는 메가폰트의 로컬 설계다. 사용자 메시지의 서체와 색 팔레트는 유지한다.

검증: npm run build; node scripts/verify-split-tone.mjs.
320×640, 390×844, 480×844에서 선택→기본값 진행→글쓰기→뒤로→조절→다른 말투→글쓰기→미리보기 및 값 보존을 확인했다.
