## 0. 테스트 전에 끝내야 하는 결정

여기가 막히면 1번의 절반이 무의미해진다. **순서가 있다.**

### 0-1. 서체 4종 확정 ⛔ 가장 급함

> **정정.** 앞서 '다정한과 정갈한이 같은 얼굴'이라고 적었는데 틀렸다.
> 네 칸을 실제로 렌더해 캡처한 결과([design/screens/faces/](screens/faces/)),
> 넷 다 의도한 서체로 정상 로드된다. 폴백 문제가 아니었다.
> **겹치는 짝은 다른 쪽이다.**

```
다정한  → jjgulwol              붓 손글씨. 기울고 불규칙   ✓ 갈린다
발랄한  → Sunflower             둥근 산세리프, 네모틀      ⛔
당당한  → seoul-namsan          고딕, 네모틀              ⛔ 위와 겹침
차분한  → kim-jung-chul-myungjo 붓 명조. 곧고 격식         ✓ 갈린다
```

(2차 피드백으로 '짓궂은'→**발랄한**, '정갈한'→**차분한**으로 바꿨다.
 '정갈한'은 음식에 붙는 말이고 '짓궂은'은 어감이 너무 특정하다는 지적.)

**문제 둘 — 하나는 이름을 고쳐 해소했고, 하나는 남았다.**

1. ~~부제가 '탈네모'인데 Sunflower는 탈네모가 아니다~~ → 부제를
   **'둥근고딕'**으로 바꿔 라벨과 그림을 맞췄다. 정직해졌을 뿐 문제가
   풀린 건 아니다.
2. **'발랄한'과 '당당한'이 골격을 공유한다.** 둘 다 네모틀 산세리프여서
   차이가 사실상 굵기로만 읽힌다. **그런데 굵기는 이미 별도 축이
   하는 일이다.** 예전에 직접 지적하셨던 그것 — "자칫 고딕 하나를 두고
   되는 꼴" — 이 지금 발랄한/당당한 사이에서 벌어지고 있다.

**따라서 조달해야 할 것은 손글씨가 아니라 '발랄한' 자리의 서체다.**
후보 조사는 세션 한도에 걸려 한 번 실패했다. 다시 돌린다.

'다정한'(jjgulwol)에도 의심은 남는다 — 붓글씨라 '다정'보다 '서예'에
가깝다. 쪽지 같은 얼굴이 필요하다면 이 칸도 바꿀 후보가 있다.
(코드 주석도 이미 '임시'라고 적혀 있었다.)

서체 선정은 라이선스(공공 설치 전시·웹폰트 임베딩·CSS 변형 허용)가
걸려 있어 **내가 혼자 정할 문제가 아니다.** 후보를 라이선스까지 확인해
추려 올리는 중이다.

### 0-2. '외벽' 대체어 ✅ 끝남 → **'벽'**

문제는 '벽'이 아니라 **'외'**였다. '외'는 건축 도면의 접두사고, 내벽과
구별해야 하는 사람(시공사)만 쓴다. 거기 서 있는 사람은 그냥 벽이라고 한다.
한 글자라 스무 번 반복돼도 닳지 않고, 코드가 이미 `/wall` · `wall.ts` ·
`WallSimulation`이라 한국어도 벽이면 어휘가 하나도 늘지 않는다.

탈락시킨 것들과 이유는 [instructions.md](instructions.md#3-어휘-원칙)에 적었다.

**진짜 결정은 낱말이 아니라 '저'를 몇 번 쓸 것인가였다.** '저'는 낱말이
아니라 손가락질이고, 손가락질은 반복하면 닳는다. 규칙 셋으로 못박았다 —
그 규칙이 기대는 물리적 전제가 아직 확정되지 않았으므로 아래 경고를 볼 것.

> ⚠ **'저 벽'은 본체가 벽을 보고 선다는 전제 위에 있다.**
> 본체(100cm 도킹 오브제)와 벽(건물 면의 디스플레이)은 다른 물건이다.
> 방향이 어긋나면 "고개를 들어 보세요"가 벽 반대쪽을 가리키게 된다.
> 보험으로 06에 **'벽을 보고 서서 꽂으세요'**를 넣어 자세를 미리
> 정렬시켰지만, 이건 보험이지 해결이 아니다. **설치 도면이 확정되는 날
> 이 결정을 먼저 다시 펼칠 것.** 어긋나면 '저'를 07 한 자리에만 남기고
> 나머지를 맨 '벽'으로 되돌린다.

## 1. 테스트가 답할 것 — 아홉 가지

물어볼 순서가 아니라 **알고 싶은 것의 중요도** 순이다.

### ① 자형 네 어휘가 통하는가 ★★★

> 다정한 / 발랄한 / 당당한 / 차분한

2차 피드백에서 형용사 방식 자체는 좋다고 했고, 낱말 둘이 바뀌었다.
넷은 따뜻함×기운의 2×2로 선다 — 다정(따뜻·낮음) 발랄(따뜻·높음)
당당(차가움·높음) 차분(차가움·낮음).

- **묻는 것** — 고르기 전에 무엇이 나올지 짐작되는가. 고른 뒤 납득되는가.
- **재는 법** — 두 방향으로 잰다.
  1. **정방향**: 이름만 보고 고르게 → 나온 서체에 놀라는가
  2. **역방향**: 서체만 보여주고 네 이름 중 붙이게 → 정방향과 짝이 맞는가
- **성공** — 양방향이 일치하는 짝이 4개 중 3개 이상
- **실패하면** — 어휘를 바꿀지 서체를 바꿀지 갈라야 한다. 역방향이
  흩어지면 서체 문제, 정방향만 흩어지면 어휘 문제다.
- ⚠ **0-1이 끝나야 유효하다.**

### ② 다른 성격이 필요한가 ★★★

네 개가 맞는 개수인지, 빠진 얼굴이 있는지.

- **재는 법** — 열린 질문. "쓰고 싶었는데 없던 말투가 있었나요?"
  네 칸을 다 보여준 **뒤에** 묻는다(앞에 물으면 유도가 된다).
- **왜 중요한가** — 이 답이 다음 항목(③)을 결정한다. 개수가 정해져야
  UI 형식이 정해진다.

### ③ Style Selector의 UI 형식 ★★★

지금은 가로 4칸. 이게 최선인지는 **개수가 정해진 뒤에야** 판단할 수 있다.

```
4개  → 지금의 가로 4칸이 맞다
5~6개 → 2×3 격자 또는 가로 스크롤
7개+ → 목록형. 카드로는 안 된다
```

- **묻는 것** — "이 화면의 목표는 '나의 목소리'를 '내가 원하는 성격'대로
  구성해보는 것"이라면, 지금 UI가 그 성격을 드러내는가.
- **재는 법** — 카드를 몇 개나 눌러보는가. 한 번 고르고 끝인가,
  왔다 갔다 하는가. **왔다 갔다 해야 정상이다** — 안 그러면 이 화면은
  선택이 아니라 통과 절차다.

### ④ 굵기 · 너비 · 기울기 ★★

**2차 피드백으로 슬라이더 → 버튼 셋으로 바꿨다.** 슬라이더는 '연속으로
조절된다'를 약속하는데 실제로는 눈금 셋이었고, 그 어긋남이 당황을 불렀다.
이제 카드와 축이 같은 손짓(누르기)이다.

- **묻는 것** — 건드리는가. 건드린 결과가 자기 뜻대로였는가.
- **재는 법** — 세 축 각각 손댄 사람 수. 손대고 원위치한 횟수.
- **실패 신호** — 아무도 안 건드린다 → 축 자체를 접거나, 카드에
  녹여야 한다. 셋으로는 부족하다는 말이 나온다 → 그때 슬라이더로 되돌린다.

### ⑤ '발화' 무대가 이 정도로 중요한가 ★★

말투 화면의 무대 이야기. 340px → 132px로 줄였고, **테두리를 없앴다**
(2차 피드백: 빈 상자가 입력창처럼 보인다). 고르기 전에는 중립 서체가
옅게 떠 있고, 카드 자체가 견본(이름을 그 서체로)이 되도록 바꿨다.

- **재는 법** — 카드를 누른 뒤 시선이 위로 가는가, 아니면 다음 카드로
  바로 가는가.
- **성공** — 카드를 누를 때마다 무대를 한 번씩 확인한다
- **실패** — 무대를 아예 안 본다 → 더 줄이거나 카드 안에 견본을 넣는다

### ⑥ 프로젝트 정보 버튼의 위계 ★★

**이번에 글자 링크 → 시작하기와 같은 폭의 테두리 버튼으로 올렸다.**
동시에 홈에 있던 소개 문구를 전부 이 안으로 넣었다.

- **묻는 것** — 이제는 누르는가. 눌러서 이해가 되는가.
- **재는 법** — 시작하기를 먼저 누르는 사람 / 정보를 먼저 여는 사람 수.
  정보를 연 사람은 몇 장까지 넘기는가.
- **성공** — 절반 이상이 시작 전에 열어본다. 연 사람은 6장을 끝까지 넘긴다
- **실패** — 그래도 안 누른다 → 홈에서 첫 장을 미리 보여주는 방식으로

### ⑦ 소개 카피의 분량 ★★

**이번에 전기가오리 방식으로 바꿨다** — 여섯 장을 옆으로 넘기며 보고,
장마다 삽화가 있다. 명세서에서 이야기로 바꾼 것.

- **재는 법** — 장당 머무는 시간. 중간에 닫는 사람의 장 번호.
- **성공** — 6장을 다 넘긴다. 마지막 장(사라짐·익명·수정불가)에 도달한다
- **실패** — 3장 이전에 닫는다 → 4장으로 줄인다

### ⑧ 메인 카피의 직관성 ★

**이번에 바꿔 놓았다.** 되돌리기 쉬우니 마음에 안 들면 말해 달라.
(2차 피드백: 01은 별도 지적 없음.)

```
전  공공의 한 줄, 당신의 형식
후  쓰면
    저 벽에 뜹니다
```

바꾼 이유는 하나다 — 홈에는 이제 3단계 띠도 태그라인도 없다. **헤드라인이
거래 전체를 혼자 져야 한다.** '공공의 한 줄, 당신의 형식'은 아름다운
제목이지만 동사가 없어서 아무것도 시키지 않는다. 그리고 이 문장은
안내판의 첫 줄과 같은 말이라, 밖에서 읽은 것을 앱이 되풀이해
'같은 장치'라는 확인을 준다.

잃은 것도 분명하다: **'형식'이라는 이 작품의 논지가 첫 화면에서
사라졌다.** 그건 이제 정보 3장('말투도 당신이 정합니다')과 02 화면
자체가 진다.

- **재는 법** — 홈만 5초 보여주고 덮은 뒤 "여기서 뭘 할 수 있을 것
  같아요?" 라고 묻는다.
- **성공** — '뭔가를 써서 저 벽에 띄운다'가 나온다
- **덤으로 볼 것** — 형식을 고를 수 있다는 걸 언제 알아채는가.
  02에 도착해서야 안다면 그건 정상인가, 늦은 것인가

### ⑨ 프리뷰 비례가 이해되는가 ★

**이번에 쓰는 화면(03)의 액자를 화면 양끝까지 늘려 놓았다** — 가운데
떠 있는 카드가 아니라 기기를 가로지르는 띠가 되도록.

- **묻는 것** — 이제 저 검은 띠가 '저기 있는 벽'으로 읽히는가.
- **재는 법** — "이 검은 부분이 뭘까요?" 라고 물었을 때의 첫 대답.
- **성공** — '화면' 또는 '벽'
- **실패** — '입력창' → 실제 벽 사진을 배경으로 깔아야 한다

## 2. 이미 고친 것 — 아홉 가지

테스트 없이도 논지가 분명해 바로 반영했다. 다음 회차에서 결과를 본다.

| 무엇 | 어떻게 |
|:--|:--|
| 홈의 소개 문구가 홈에 있을 일인가 | 서브카피·1·2·3을 전부 프로젝트 정보로 옮김 |
| 정보가 제품 명세서 같다 | 여섯 장 슬라이드 + 삽화. 순서대로 |
| '여기에 말을 적어보세요' | **'여기를 눌러 쓰세요'** — 자판이 열린다는 걸 말한다 |
| 프리뷰 비례가 어색하다 | 03 액자를 화면 끝까지 늘림 |
| 04가 03과 다를 게 없다 | **시뮬레이션으로 교체** — 빈 벽 → 튀어오름 → 축소 → 이웃들과 표류 |
| 05 로딩이 스플래시와 같다 | 가로 막대 → **파문 + 링** |
| 10초가 아니라 30초, 빼면 메아리 | 상한 30초로. 벽은 '폰 빠짐' 신호에 강조를 끝냄 |
| 07·08이 화면 전체를 쓴다 | **아래 절반만** 사용. 위 절반은 홈 안이라 안 보임 |
| 주소창이 보기 싫다 | **전체 화면** 버튼. 아이폰은 '홈 화면에 추가' 안내 |
| '외벽'이 어휘에서 동떨어진다 | **'벽'**으로. 시선이 화면 밖으로 나가는 네 자리에만 '저 벽' |

### 07·08을 절반만 쓰는 이유

폰이 위쪽부터 세로로 꽂히므로 서 있는 사람에게는 **아래 절반만** 남는다.
그 위에 쓴 글자는 홈 안에서 혼자 빛난다.

08은 예외가 하나 있다. 07에서 '폰을 뺐어요'를 눌러서 온 사람은 이미
폰이 손에 있으므로 화면 전체를 쓴다. 30초가 다 되어 저절로 넘어온
사람만 절반을 쓴다 — 그 사람은 아직 꽂혀 있기 때문이다.

## 3. 2차 피드백 (9/6 저녁) — 열두 가지, 전부 반영

| 화면 | 지적 | 반영 |
|:--|:--|:--|
| 01 이전 | "써보신 적 있으세요?" 네/아니요로 갈라 처음이면 인포를 바로 | 홈 헤드라인 아래 **"메가폰트, 처음이세요?"** — [처음이에요 → 6장 → 시작하기] / [써봤어요 → 바로] |

| 02 | '다정한…'이 갑자기 등장 | 카드 이름을 **그 서체로** 찍고 계열명(손글씨·둥근고딕·고딕·명조)을 상시 표시 |
| 02 | '정갈한'은 음식 말, '짓궂은'은 애매 | **차분한 · 발랄한**으로 |

| 03 | 컬러가 뭔지 모르겠다 | **"색 바꾸기 01/10"** 으로 이름 붙이고 액자 바로 아래로 |

| 04 | '이대로 맡기기' 비직관 | **"발화하기"** |

**단계 표기**: 화면 이름을 '자형·색·미리보기'에서 **'말투 · 한 줄 · 벽에서 보기'**로
바꿨다. '자형'은 타이포그래피 용어고 '말투'는 누구나 아는 말이다 —
"'다정한 발화를 하겠다'처럼 태도와 연결하는 논지"에 그대로 붙는다.

**토스식 예고** — 조사는 직접 하신다고 하셨다. 지금 넣은 것은 최소 형태다:
다음 버튼이 "다음 · (다음 단계 이름)"으로 답한다. 그 이상은 조사 결과를 보고.

### 아이폰 주소창에 대해

솔직하게: **사파리에는 전체 화면 기능이 없다.** iPad는 되고 iPhone은
안 된다. 주소창을 지우는 방법은 하나뿐이다 — 공유 → 홈 화면에 추가로
설치해서 여는 것. 버튼을 누르면 그 방법을 안내한다.

QR로만 들어오게 주소를 길게 만들 계획이라면, **QR 옆 안내판에
'홈 화면에 추가' 세 줄을 같이 박아 두는 것**을 권한다. 앱 안에서만
말하면 이미 늦다.
