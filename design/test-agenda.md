# 무엇을 테스트로 정하고, 무엇을 먼저 정할 것인가

> 2026-09-06. 교수 피드백 이후 나온 의견들을 두 갈래로 갈라 정리한다.
> 실행 절차는 [user-test.md](user-test.md), 이 문서는 **의제**만 다룬다.

의견 하나하나가 다 테스트 항목은 아니다. 셋으로 갈린다.

| 갈래 | 뜻 | 개수 |
|:--|:--|--:|
| **0. 먼저 정할 것** | 테스트가 답을 줄 수 없다. 내가 정하고 들어가야 한다 | 2 |
| **1. 테스트가 답한다** | 사람을 앉혀 봐야 알 수 있다 | 9 |
| **2. 이미 고쳤다** | 논지가 분명해 바로 반영했다 | 9 |

## 0. 테스트 전에 끝내야 하는 결정

여기가 막히면 1번의 절반이 무의미해진다. **순서가 있다.**

### 0-1. 서체 4종 확정 ⛔ 가장 급함

지금 '다정한'과 '정갈한'이 **같은 얼굴**이다. 손글씨 서체를 못 구해
둘 다 세리프 계열로 떨어져 있다. 이 상태로 테스트하면 참가자가 둘을
헷갈릴 텐데, 그건 **어휘 문제가 아니라 재료 문제**여서 데이터가 못 된다.

```
다정한  → 손글씨   ← 미확정. 이게 없으면 네 칸이 벌어지지 않는다
짓궂은  → 탈네모   ← 확정
당당한  → 고딕     ← 확정
정갈한  → 명조     ← 확정
```

서체 선정은 라이선스(설치 전시·상업 여부)가 걸려 있어 **내가 고를 문제가
아니다.** 후보를 추려 올리겠다.

### 0-2. '외벽'을 대신할 낱말

앱 전체에서 스무 번 넘게 반복되는 말이라 이걸 정해야 나머지 카피가 선다.
지금 임시로 **'벽'**을 넣어 두었다. 대체어 조사가 돌아가는 중이고,
결과가 나오면 한 번에 갈아끼운다.

## 1. 테스트가 답할 것 — 아홉 가지

물어볼 순서가 아니라 **알고 싶은 것의 중요도** 순이다.

### ① 자형 네 어휘가 통하는가 ★★★

> 다정한 / 짓궂은 / 당당한 / 정갈한

- **묻는 것** — 고르기 전에 무엇이 나올지 짐작되는가. 고른 뒤 납득되는가.
- **재는 법** — 두 방향으로 잰다.
  1. **정방향**: 이름만 보고 고르게 → 나온 서체에 놀라는가
  2. **역방향**: 서체만 보여주고 네 이름 중 붙이게 → 정방향과 짝이 맞는가
- **성공** — 양방향이 일치하는 짝이 4개 중 3개 이상
- **실패하면** — 어휘를 바꿀지 서체를 바꿀지 갈라야 한다. 역방향이
  흩어지면 서체 문제, 정방향만 흩어지면 어휘 문제다.
- ⚠ **0-1이 끝나야 유효하다.**

### ② 다른 성격이 필요한가 ★★★

네 개가 맞는 개수인지, 빠진 얼굴이 있는지.

- **재는 법** — 열린 질문. "쓰고 싶었는데 없던 말투가 있었나요?"
  네 칸을 다 보여준 **뒤에** 묻는다(앞에 물으면 유도가 된다).
- **왜 중요한가** — 이 답이 다음 항목(③)을 결정한다. 개수가 정해져야
  UI 형식이 정해진다.

### ③ Style Selector의 UI 형식 ★★★

지금은 가로 4칸. 이게 최선인지는 **개수가 정해진 뒤에야** 판단할 수 있다.

```
4개  → 지금의 가로 4칸이 맞다
5~6개 → 2×3 격자 또는 가로 스크롤
7개+ → 목록형. 카드로는 안 된다
```

- **묻는 것** — "이 화면의 목표는 '나의 목소리'를 '내가 원하는 성격'대로
  구성해보는 것"이라면, 지금 UI가 그 성격을 드러내는가.
- **재는 법** — 카드를 몇 개나 눌러보는가. 한 번 고르고 끝인가,
  왔다 갔다 하는가. **왔다 갔다 해야 정상이다** — 안 그러면 이 화면은
  선택이 아니라 통과 절차다.

### ④ 굵기 · 너비 · 기울기 슬라이더 ★★

- **묻는 것** — 건드리는가. 건드린 결과가 자기 뜻대로였는가.
- **재는 법** — 세 축 각각 손댄 사람 수. 손대고 원위치한 횟수.
- **실패 신호** — 아무도 안 건드린다 → 축 자체를 접거나, 자형 카드에
  녹여야 한다. 다 건드리는데 결과가 마음에 안 든다 → 눈금이 잘못됐다.

### ⑤ '발화' 프리뷰 칸이 이 정도로 중요한가 ★★

자형 화면 위쪽 무대 이야기. **이번에 340px → 168px로 줄여 놓았다.**
줄인 게 맞는지 확인한다.

- **재는 법** — 카드를 누른 뒤 시선이 위로 가는가, 아니면 다음 카드로
  바로 가는가.
- **성공** — 카드를 누를 때마다 무대를 한 번씩 확인한다
- **실패** — 무대를 아예 안 본다 → 더 줄이거나 카드 안에 견본을 넣는다

### ⑥ 프로젝트 정보 버튼의 위계 ★★

**이번에 글자 링크 → 시작하기와 같은 폭의 테두리 버튼으로 올렸다.**
동시에 홈에 있던 소개 문구를 전부 이 안으로 넣었다.

- **묻는 것** — 이제는 누르는가. 눌러서 이해가 되는가.
- **재는 법** — 시작하기를 먼저 누르는 사람 / 정보를 먼저 여는 사람 수.
  정보를 연 사람은 몇 장까지 넘기는가.
- **성공** — 절반 이상이 시작 전에 열어본다. 연 사람은 6장을 끝까지 넘긴다
- **실패** — 그래도 안 누른다 → 홈에서 첫 장을 미리 보여주는 방식으로

### ⑦ 소개 카피의 분량 ★★

**이번에 전기가오리 방식으로 바꿨다** — 여섯 장을 옆으로 넘기며 보고,
장마다 삽화가 있다. 명세서에서 이야기로 바꾼 것.

- **재는 법** — 장당 머무는 시간. 중간에 닫는 사람의 장 번호.
- **성공** — 6장을 다 넘긴다. 마지막 장(사라짐·익명·수정불가)에 도달한다
- **실패** — 3장 이전에 닫는다 → 4장으로 줄인다

### ⑧ 메인 카피의 직관성 ★

> "공공의 한 줄, 당신의 형식"

- **재는 법** — 홈만 5초 보여주고 덮은 뒤 "여기서 뭘 할 수 있을 것
  같아요?" 라고 묻는다.
- **성공** — '뭔가를 써서 어딘가에 띄운다'가 나온다
- **실패** — '형식'이 무슨 뜻인지 되묻는다 → 대체안이 조사 중이다

### ⑨ 프리뷰 비례가 이해되는가 ★

**이번에 쓰는 화면(03)의 액자를 화면 양끝까지 늘려 놓았다** — 가운데
떠 있는 카드가 아니라 기기를 가로지르는 띠가 되도록.

- **묻는 것** — 이제 저 검은 띠가 '저기 있는 벽'으로 읽히는가.
- **재는 법** — "이 검은 부분이 뭘까요?" 라고 물었을 때의 첫 대답.
- **성공** — '화면' 또는 '벽'
- **실패** — '입력창' → 실제 벽 사진을 배경으로 깔아야 한다

## 2. 이미 고친 것 — 아홉 가지

테스트 없이도 논지가 분명해 바로 반영했다. 다음 회차에서 결과를 본다.

| 무엇 | 어떻게 |
|:--|:--|
| 홈의 소개 문구가 홈에 있을 일인가 | 서브카피·1·2·3을 전부 프로젝트 정보로 옮김 |
| 정보가 제품 명세서 같다 | 여섯 장 슬라이드 + 삽화. 순서대로 |
| '여기에 말을 적어보세요' | **'여기를 눌러 쓰세요'** — 자판이 열린다는 걸 말한다 |
| 프리뷰 비례가 어색하다 | 03 액자를 화면 끝까지 늘림 |
| 04가 03과 다를 게 없다 | **시뮬레이션으로 교체** — 빈 벽 → 튀어오름 → 축소 → 이웃들과 표류 |
| 05 로딩이 스플래시와 같다 | 가로 막대 → **파문 + 링** |
| 10초가 아니라 30초, 빼면 메아리 | 상한 30초로. 벽은 '폰 빠짐' 신호에 강조를 끝냄 |
| 07·08이 화면 전체를 쓴다 | **아래 절반만** 사용. 위 절반은 홈 안이라 안 보임 |
| 주소창이 보기 싫다 | **전체 화면** 버튼. 아이폰은 '홈 화면에 추가' 안내 |

### 07·08을 절반만 쓰는 이유

폰이 위쪽부터 세로로 꽂히므로 서 있는 사람에게는 **아래 절반만** 남는다.
그 위에 쓴 글자는 홈 안에서 혼자 빛난다.

08은 예외가 하나 있다. 07에서 '폰을 뺐어요'를 눌러서 온 사람은 이미
폰이 손에 있으므로 화면 전체를 쓴다. 30초가 다 되어 저절로 넘어온
사람만 절반을 쓴다 — 그 사람은 아직 꽂혀 있기 때문이다.

### 아이폰 주소창에 대해

솔직하게: **사파리에는 전체 화면 기능이 없다.** iPad는 되고 iPhone은
안 된다. 주소창을 지우는 방법은 하나뿐이다 — 공유 → 홈 화면에 추가로
설치해서 여는 것. 버튼을 누르면 그 방법을 안내한다.

QR로만 들어오게 주소를 길게 만들 계획이라면, **QR 옆 안내판에
'홈 화면에 추가' 세 줄을 같이 박아 두는 것**을 권한다. 앱 안에서만
말하면 이미 늦다.
