## 1. 서체 — 네 갈래로 쓴다

| 갈래 | 서체 | 어디에 |
|:--|:--|:--|
| **UI 라틴·숫자** | Lineal VF (가변 100–900) | 모든 화면의 제목·본문·버튼 |
| **UI 한글** | Pretendard Variable (가변 100–900) | 같은 자리의 한글 |
| **발화** | 네 종 (아래) | 참여자가 쓴 한 줄 |
| **단계 표시** | Pretendard Variable 고정 | `1 / 5 · 성격` |

### 알아 둘 것 하나 — 한글은 Lineal VF가 아니다

`--ui-font`는 `'Lineal VF', 'Pretendard Variable', …` 순서인데, Lineal VF의
`@font-face`에 **`unicode-range: U+0000-024F`** 가 걸려 있다. 라틴과 숫자만
그 글꼴이 맡고 **한글은 전부 Pretendard가 그린다.** 브라우저가 계산한
`font-family`는 언제나 'Lineal VF'라고 답하므로 측정값만 보면 헷갈린다.

즉 한 줄 안에 한글과 숫자가 섞이면 **두 글꼴이 같이 선다.** 굵기·자간을
조정할 때 이 둘의 짝을 함께 봐야 한다.

### 발화 서체 네 종

| 성격 | 서체 | 출처 | 가변? |
|:--|:--|:--|:--|
| 당당한 | seoul-namsan (서울남산) | Adobe Fonts | 가변 |
| 차분한 | kim-jung-chul-myungjo (김정철명조) | Adobe Fonts | 가변 |
| 다정한 | jjgulwol (붓글씨) | Adobe Fonts | 가변 — *임시. '다정'보다 '서예'에 가깝다는 의심* |
| 발랄한 | OG 르네상스 비밀 | `public/fonts` (로컬) | **정적** |

**'발랄한'만 정적이다.** 무게 축을 움직여도 진짜 굵기가 아니라 브라우저의
합성 굵기로 답한다. 그래서 이 칸만 획을 따로 살찌워 보정한다.

→ `src/lib/palettes.ts` (`fontMap`)

같은 크기·같은 굵기로 찍어도 잉크 높이와 무게가 달라 보여서 잰 값이다.

| 성격 | 크기 배수 | 기준선 보정 |

| 차분한 | 1.0 | −0.0486em |

## 2. UI 활자 위계 — 화면에서 무엇이 무엇인가

화면 순서는 **한 줄 → 성격 → 조율 → 색 → 미리보기**다(2026-09-19에 뒤집혔다).
같은 역할은 모든 화면에서 같은 값이라, 아래 한 벌이 전부다.

### 화면 어디에 있는 글자인가

```
┌──────────────────────────────────────┐
│  ‹ 한 줄 다시 쓰기        2 / 5 · 성격 │ ← 뒤로 문구 · 단계 표시
│                                      │
│  어떤 성격으로                        │ ← 질문 제목
│  말해볼까요?                          │
│  마음에 드는 것을 골라주세요.          │ ← 보조 설명
│                                      │
│  ┌──────────┬──────────┐             │
│  │  말하지   │  말하지   │             │ ← 발화 견본 (성격 카드)
│  │  당당한   │  차분한   │             │ ← 카드 이름표
│  └──────────┴──────────┘             │
│                                      │
│      [ 이 성격으로 할게요 ]            │ ← 주 버튼
└──────────────────────────────────────┘
```

### 값

| 무엇 | 실제로 이런 글자 | 어디에 | 크기 | 굵기 | 행간 | 자간 |
|:--|:--|:--|--:|--:|--:|--:|
| **질문 제목** | `어떤 성격으로 말해볼까요?` | 화면 위, 다섯 단계 전부 | **30px** | 600 | 1.3 | −0.02em |
| **보조 설명** | `마음에 드는 것을 골라주세요.` | 제목 바로 아래 | **16px** | 400 | 1.5 | 0 |
| **주 버튼** | `이 성격으로 할게요` · `다 썼어요` | 화면 맨 아래 | 17px | 600 | *normal* | −0.01em |
| **단계 표시** | `2 / 5 · 성격` | 오른쪽 위 | 14px | 400 | *normal* | 0 |
| **뒤로 문구** | `한 줄 다시 쓰기` | 왼쪽 위, ‹ 옆 | 14px | 400 | *normal* | 0.02em |
| **축 이름** | `크기` `빠르기` `무게` | 03 조율, 눈금 위 왼쪽 | 16px | 600 | *normal* | −0.01em |
| **축 값** | `보통` `아주 크게` | 같은 줄 오른쪽 | 14px | 400 | *normal* | 0 |
| **카드 이름표** | `당당한` `차분한` | 02 성격, 견본 아래 | 12px | 400 | *normal* | 0.02em |
| **글자 수** | `12/60` | 01 한 줄, 오른쪽 아래 | 14px | 400 | *normal* | 0.02em |
| **워드마크** | `MEGAFONT` | 홈 한가운데 | 69.3px<sup>※</sup> | 1150 | 1.2 | 0 |
| **홈 부제** | 워드마크 아래 한 줄 | 홈 | 16px | 500 | 1.5 | 0 |
| **홈 버튼** | `처음이에요` · `써봤어요` | 홈 아래 | 17px | 600 | *normal* | 0 |
| **캐릭터 말** | 홈 캐릭터가 뱉는 한 마디 | 홈 | 32.6px | 900 | 1 | 0 |

<sup>※</sup> 워드마크는 화면 폭의 19.8%라 기기마다 다르다. 390px 기준 69.3px.

*normal*은 **정해 두지 않았다는 뜻**이다 — 글꼴이 알아서 정한다. 아래 5절 참조.

## 3. 발화 활자 — 참여자가 쓴 그 한 줄

같은 한 줄인데 화면마다 크게 달라진다. **의도된 것이고, 이유가 다르다.**
아래는 `말하지 않으면 아무도 모른다는 걸 여기서 배웠다`(당당한, 크기 '보통')를
실제로 재 본 값이다.

| 화면 | 크기 | 행간 | 무엇을 보여주려고 |
|:--|--:|--:|:--|
| **01 한 줄** (자판 내린 뒤) | 53px | 1.5 | 쓴 것을 **읽히게**. 여기만 화면 서체다 |
| **02 성격** (카드 넷) | 36px | 1.15 | 네 서체의 **획 차이**. 여섯 자로 접어 키웠다 |
| **03 조율** (견본) | 20.1px | 1.4 | 크기·빠르기·무게 축의 **결과** |
| **04 색** | 54px | 1.5 | 색이 **면으로** 보이는 것 |
| **05 미리보기** (벽 안) | 14.5px | 1.5 | 벽에서의 **실제 비율** |
| **05 미리보기** (이웃 말들) | 8.4px | 1.2 | 풍경의 밀도 |

자간은 발화 쪽 전부 **0**이다.

**01만 화면 서체(Pretendard)로 뜬다.** 아직 성격을 안 골랐기 때문이고, 그게
이 앱의 '원본'이다. 02에서 성격을 고르는 순간 얼굴이 바뀐다.

**03이 작아 보이는 것은 크기 축이 비율이기 때문이다.** '보통'은 그 말이 벽에서
쓸 수 있는 자리의 73%를 쓰겠다는 뜻이다(`SIZE_FILLS`). '아주 크게'로 밀면
같은 자리에서 30px까지 간다.

→ `src/phases/PhaseCompose.tsx` (`composeFontSize`) · `PhaseGlyph.tsx`
(`CARD_CHARS`) · `PhaseTone.tsx` (`STAGE_H`) · `src/lib/fit.ts`

`src/styles/tokens.css` 한 파일에만 있다. 하드코딩된 px를 새로 넣지 않는다.

|:--|--:|:--|
| `--fs-h1` | 36px | 08 완료·07 발화 중 제목 |
| `--fs-h2` | **30px** | 질문 제목 전부 |
| `--fs-h3` | 24px | 카운트다운·로딩 |
| `--fs-h4` | 22px | 안내 슬라이드 소제목 |
| `--fs-body` | **16px** | 본문·축 이름 |
| `--fs-body-s` | 14px | 축 값·보조 |

있다). 토큰으로 올릴지는 정해야 한다.

## 5. 아직 아무도 안 정한 자리

**행간이 `normal`인 것들.** 버튼·라벨·축 이름·단계 표시가 전부 그렇다.
`normal`은 글꼴이 정하는 값이라 Lineal VF와 Pretendard가 서로 다르게
답한다 — 즉 **한글과 라틴의 줄 높이가 지금 어긋나 있다.** 한 줄짜리라
티가 안 날 뿐이다.

**자간이 제각각이다.** 제목 −0.02em · 버튼 −0.01em · 라벨 +0.02em ·
그 외 0. 라벨의 +0.02em은 옛 모노 라벨의 흔적이고, 지금 그 자리는
Pretendard다.

**`--fs-h1`(36px)과 `--fs-h2`(30px)의 간격.** 질문 제목은 전부 h2를 쓰고
h1은 마지막 두 화면에만 나온다. 위계라기보다 두 덩이로 갈려 있다.

## 다시 재는 법

값을 고친 뒤 이 문서를 갱신하려면, `npm run dev`를 띄운 채로 브라우저를
몰아 화면마다 `getComputedStyle`을 읽으면 된다(`peek` 스킬 · 화면 이동은
`scripts/lib/drive.mjs`가 들고 있다). 읽는 속성은 다섯이다 —
`font-family` · `font-size` · `font-weight`(또는 `font-variation-settings`)
· `line-height` · `letter-spacing`.
