# 참여자 앱 수정 — 2026-09-07

사용자 요청을 DESIGN.md의 서체 권장보다 우선하여 반영했다.

- UI 한글: 로컬 Pretendard Variable. 영문·숫자: 로컬 Lineal VF(U+0000–024F).
- LinealVF.ttf는 PC에 설치된 파일에서 가져왔다. 본문 400, 보조 라벨 500, 주요 제목·버튼 600, 큰 제목 700으로 시작하며 별도 광학 보정은 하지 않았다.
- 일반 제목 30px/600, 작은 제목 24px/600, 본문 16px/400, 보조 본문 14px. 320px 화면의 긴 질문은 24px로 조정한다.
- 말투 견본과 사용자가 작성하는 글은 고른 서체를 계속 사용한다.
- 모든 요소의 기본 줄바꿈은 keep-all / normal: 낱말 중간에서 강제로 자르지 않는다.
- 홈 상단 라벨, 큰 워드마크와 드래그 루프, 버튼 부연 설명, 버전·구분선을 제거했다.
- 소개는 세로 스크롤이며, 아래 화살표로 다음 섹션에 이동한다. 하단 시작하기는 언제든 사용할 수 있다. 마지막 섹션은 화살표를 숨긴다.
- 뒤로 버튼은 테두리 없이 2.6px 화살표, 터치 영역 44px.
- 말투 선택은 2×2 카드, 견본, 3개 조절 행 순서. 작은 화면에서는 페이지 자체가 세로로 스크롤된다.

검증: npm run build 통과. 320/390/480px에서 가로 넘침 없음, 소개 6개 섹션 이동, 선택 전 다음 비활성 및 선택 후 글쓰기 이동 확인. 320px에서 가장 넓고 기울어진 견본이 영역 안에 들어가는지 확인했다.
접근성 자동 감사는 axe-core CDN 로드 실패로 완료하지 못했다.
