# 파이 — 벽을 띄우고 스위치를 읽는다

파이가 하는 일은 둘뿐이다. **벽 화면은 여기 없다** — 그건 웹이고 Vercel에
있다. 파이는 그걸 열어 보여줄 뿐이다.

| 파일 | 하는 일 |
|:--|:--|
| `kiosk.sh` | 부팅하면 `/wall`을 전체화면으로 연다 |
| `switch.py` | 홈의 스위치(11번 핀)를 읽어 벽에 알린다 |
| `install.sh` | 위 둘을 부팅에 심는다. 한 번만 돌린다 |

## 배선

| 스위치 | 파이 |
|:--|:--|
| 한쪽 | 11번 핀 (GPIO 17) |
| 반대쪽 | 6번 핀 (GND) |

저항은 안 단다 — 파이 안의 풀업을 쓴다.

## 까는 법

```bash
# 개발 PC에서 파이로 옮긴다
scp -r pi <사용자>@<파이주소>:~/megafont

# 파이에서
cd ~/megafont
cp megafont.env.example megafont.env
nano megafont.env        # 값 세 개를 채운다
bash install.sh
sudo reboot
```

## 신호가 흐르는 길

```
폰이 07 도킹 화면에 도착
   → 대기 자리에 제 이름을 올린다 (control/dock 의 waitSession)
      — 이걸로 **다음 꽂힘이 누구의 것인지**가 미리 정해진다
      — 5초마다 갱신한다. 화면을 떠나면 15초 뒤 자리가 풀린다

폰이 홈에 꽂힘
   → 스위치 닫힘 (11번 핀)
   → switch.py 가 plugged=true · switchId=<새 번호> · switchAt=<지금> 을 쓴다
   → 대기 자리의 주인인 그 폰이 새 번호를 보고,
      제 글의 id와 함께 송출 시작(startId · startedAt)을 확정한다
   → **확정된 뒤에야** 폰이 발화 중 화면으로 넘어간다
   → 벽이 같은 사건을 보고 그 글을 큰 상자로 띄운다
      — 30초는 양쪽 다 switchAt 에서 센다

폰을 뺌
   → 스위치 열림 → plugged=false · switchAt=<지금>
   → 벽이 큰 상자를 잔상으로 내려앉히고, 폰은 완료 화면으로 간다
```

**스위치는 '어느 글이냐'를 모른다.** 그건 폰이 안다. 스위치는 "꽂혔다"와
"언제"만 말하고, 글을 지목하는 일은 대기 자리의 주인이 한다.

**번호가 왜 필요한가.** 앞사람이 폰을 안 빼고 가면 스위치는 계속 닫혀 있다.
참/거짓만으로는 그 상태와 "방금 꽂혔다"를 가를 수 없어서, 07에 들어온 다음
사람이 화면에 닿자마자 넘어가 버렸다. 이제 폰은 제가 도착했을 때의 번호를
기억해 두고 그것과 **다른** 번호만 제 꽂음으로 센다.

**시각도 산출물이다.** 파이에는 시계 배터리가 없어 부팅 직후의 시각이
엉뚱하다. 폰과 벽이 그 값에서 30초를 세므로, switch.py는 NTP가 맞춰 줄
때까지 기다렸다 시작한다.

## 값을 고쳤으면

서비스는 켜질 때 값을 한 번만 읽는다. `megafont.env`를 고쳤으면 다시 띄워야
새 값을 든다 — `install.sh`를 다시 돌리면 알아서 그렇게 하고, 이것만 쳐도 된다:

```bash
systemctl --user restart megafont-switch
```

## 다른 와이파이로 옮길 때

파이를 새 와이파이에 붙이는 것 말고는 할 일이 없다. 값 셋은 전부 인터넷
너머의 것이라 어느 망에서든 같다. 벽은 인터넷이 잡힐 때까지 기다렸다가
연다(`kiosk.sh`). 파이 주소는 망마다 바뀌므로 SSH는 이름으로 붙는다:

```bash
ssh <사용자>@megafont.local
```

## 안 될 때

| 증상 | 볼 곳 |
|:--|:--|
| 스위치를 눌러도 아무 일 없음 | `sudo journalctl -f _SYSTEMD_USER_UNIT=megafont-switch.service` |
| 폰에 "설치물과 연결이 안 돼요" | switch.py가 죽었거나 와이파이가 끊겼다. 위 로그 |
| 폰에 "앞의 폰이 아직 꽂혀 있어요" | 홈에 폰이 남아 있거나 스위치가 눌린 채 걸렸다. 홈을 비우면 풀린다 |
| 폰에 "다른 분이 먼저 기다리고 있어요" | 앞 차례가 아직 안 끝났다. 그 폰이 떠나면 15초 안에 풀린다 |
| 남은 시간이 폰과 벽에서 다름 | 파이 시계. `timedatectl` 로 NTP 동기를 본다 |
| 벽이 안 뜸 | 와이파이. `megafont.env`의 `MEGAFONT_URL` |
| 옛날 벽이 뜸 | 아직 배포 안 된 것이다 |
| "키링이 잠겼습니다" 창 | `kiosk.sh`의 `--password-store=basic`이 막는다 |
