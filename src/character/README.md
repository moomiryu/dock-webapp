# 캐릭터

홈에 캐릭터가 **둘** 있다. 이름이 비슷해서 자주 헷갈린다.

| | 무엇 | 파일 | 클래스 |
|---|---|---|---|
| **큰 메가폰트** | 한가운데 서서 두둥실 떠 있고, 포즈를 바꿔 돌아본다 | `HomeCharacter.tsx` | `.home-char*` |
| **작은 것들** | 배경을 가로질러 걸어 지나가는 여섯 | `HomeCrowd.tsx` | `.home-crowd` · `.walker` · `.w-*` |

둘의 CSS는 `src/styles/app.css`의 **'캐릭터' 섹션 한 곳**에 있다.
2026-09-20 전에는 네 군데에 흩어져 있었고 그중 둘은 죽은 값이었다 —
다시 흩뜨리지 않는다.

## 이 폴더의 파일

```
HomeCharacter.tsx   큰 메가폰트. 포즈·표정·말·그림자를 전부 들고 있다
  morph.ts          포즈 사이를 잇는 기하. 점끼리 짝지어 보간한다
HomeCrowd.tsx       작은 것들. 태어나고 걸어가고 나간다
  walker.ts         작은 것의 몸 부품 (머리·몸·다리 둘·눈 넷·그림자)
pos.ts              큰 것이 지금 어디 있는지. 둘이 같이 읽고 쓰는 값 하나
```

`pos.ts`가 따로 있는 이유: 작은 것들이 큰 것을 따라다니려면 매 프레임 그
자리를 알아야 하는데, 초당 60번 React 상태를 갱신하면 홈 전체가 그만큼 다시
그려진다. 그래서 값 하나를 모듈이 들고 있고 그리는 쪽이 읽는다.

## 그림 원본은 여기 없다

작가의 폴더에 있다. **코드가 그 경로를 직접 읽으므로 폴더를 옮기면 앱이
깨진다** — 2026-09-20에 한 번 그렇게 됐다.

```
by_moomiryu/Renewal_v1/
  Character/megafont/   큰 것의 포즈 아홉   ← morph.ts가 통째로 읽는다
  Character/eye/        눈 아홉             ← morph.ts가 통째로 읽는다
  Character/people/     작은 것의 세 자세
  Tutorial/             소개 화면 그림      ← InfoOverlay.tsx가 이름으로 부른다
  Slider/               손잡이 스케치
```

폴더가 곧 필터다. `megafont/`와 `eye/`는 통째로(`*.svg`) 불러 오므로 **거기
안 쓰는 그림을 넣으면 번들에 그대로 실린다.** 전에 스케치가 섞여 들어와
번들이 219KB→296KB, 227KB→525KB로 뛴 적이 두 번 있다.

**작은 것은 그림을 안 읽는다.** `people/`의 SVG를 통짜로 넣지 않고
`walker.ts`에 좌표로 옮겨 적었다 — 표정을 갈아끼우고 몸 색을 파랑에서
빨강으로 건너가게 해야 하는데, 문자열째로 심으면 손댈 데가 없어서다.
그래서 **`people/`을 고쳐도 화면은 안 바뀐다.** walker.ts를 같이 고쳐야 한다.

`by_moomiryu/Past/`는 옛 그림이고 지금 아무 데서도 안 쓴다.

## 나팔에서 나오는 말

`src/components/HomeVoices.tsx`는 이 폴더 밖에 있지만 큰 메가폰트에 붙어
있다 — 나팔 쪽에서 짧은 말들이 흘러나와 배경으로 흩어진다. `pos.ts`를
읽어 자리를 잡는다. CSS는 캐릭터 섹션 안에 같이 있다.
